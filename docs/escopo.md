# Problema, público-alvo, descrição de cada página e o que contém em cada uma delas

Problema:
   A dificuldade que muitas pessoas enfrentam para encontrar filmes de maneira rápida, organizada e acessível. Muitas vezes, os usuários não sabem qual filme assistir, têm dificuldade para encontrar informações sobre os títulos, como sinopse, gênero, classificação e avaliações, ou precisam acessar vários sites diferentes para encontrar essas informações. Dessa forma, o site busca facilitar a experiência dos usuários, reunindo filmes e suas principais informações em um único lugar, tornando a busca e a escolha de filmes mais simples, prática e rápida.

Público-alvo:
    O site é destinado a todos os públicos, especialmente pessoas que gostam de assistir filmes e procuram uma maneira fácil e prática de conhecer novos títulos e escolher o que assistir.

- Pag2: -> Essa página vai ter Catalogo de filmes.

- Pag3: -> Essa página vai ter Filmes que ganharam o osca.

- Pag4: -> Essa página vai ter Tops 5 melhores atores.

- Pag5: -> Essa página vai ter Filme que marcou cada geração.

- Pag6: -> Essa página vai ter Nossos contatos.
